## 📘 Deskripsi Proyek

Proyek ini merupakan hasil pengerjaan **Ujian Tengah Semester (UTS)** untuk mata kuliah **Pemrograman Web 1**.  
Aplikasi ini dibangun menggunakan **HTML, CSS, dan JavaScript murni (tanpa framework)** dengan struktur file yang terpisah dan rapi sesuai standar pengembangan web dasar.  

Aplikasi ini menampilkan **simulasi sistem katalog dan pemesanan buku** dengan beberapa fitur utama, yaitu:

1. **Login Akun**  
   Pengguna dapat login menggunakan email dan password yang telah terdaftar di file `data.js`.

2. **Dashboard Katalog Buku**  
   Menampilkan daftar buku lengkap beserta kode, nama, jenis, edisi, stok, harga, dan gambar.  
   Termasuk fitur **Tambah Buku Baru** yang menambahkan data secara dinamis ke dalam tabel.

3. **Informasi Stok Buku**  
   Menampilkan informasi stok buku yang ada (read-only).

4. **Tracking Pengiriman**  
   Simulasi pelacakan pengiriman dengan Nomor DO (contoh: `NOMORDO`), menampilkan status dan estimasi waktu tiba.

5. **Form Pemesanan Buku (Checkout)**  
   Form simulasi pemesanan buku. Setelah form dikirim, hasil pesanan langsung muncul di halaman tanpa reload.

## ⚙️ Cara Menjalankan Aplikasi

1. Download atau clone repository ini.  
2. Buka folder `UTS_Web1` di **Visual Studio Code**.  
3. Jalankan menggunakan **Live Server**.  
4. Buka di browser:
   - **Login:** `login.html`
   - **Dashboard:** `dashboard.html`
   - **Stok Buku:** `stok.html`
   - **Tracking:** `tracking.html`
   - **Form Pemesanan:** `checkout.html`
